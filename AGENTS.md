# Instructions for Codex

To make a RentOk icon or illustration, follow
`skill/rentok-illustration/SKILL.md` step by step, with these changes:

- The references are this repo; skip the clone in the preflight (set
  `RENTOK_ILLUSTRATIONS_HOME` to this folder).
- You generate the image yourself with your image tool. Attach the reference
  board for the kind (see `style.md`) and 1–2 files from `approved/`, and
  follow every rule in `style.md`.
- Never draw text in an image. Transparent square PNG only.
